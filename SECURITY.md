# Security Policy
## Supported Versions
We support the latest stable branch of eSusFarm/GENFIN-AFRICA. Security fixes are back-ported as needed.
## Reporting a Vulnerability
Please report vulnerabilities via **admin@esusfarm.africa*.
- We aim to acknowledge receipt within 72 hours.
- Fixes will be prioritized and, where possible, released within 30 days.
- Please **do not** disclose publicly until we have confirmed and patched the issue.
You may optionally encrypt reports with our GPG key (published on our website).
## Security Practices
- All network traffic is TLS-encrypted.
- File uploads are scanned for malware and size/type restrictions are enforced.
- Sensitive data is minimized and, where possible, pseudonymized.
- Production secrets are rotated regularly and not stored in repositories.
## Responsible Disclosure
We follow a coordinated disclosure process: once patched, credits are given to the reporter unless anonymity is requested.
